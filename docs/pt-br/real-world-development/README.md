Explore o GitHub Copilot ao longo do ciclo de vida do desenvolvimento de software com cenários realistas, um aplicativo completo e um backlog compartilhado. Trabalhe de forma iterativa para planejar alterações, criar código, testar o comportamento, revisar pull requests e gerenciar tarefas com agentes.

## Cenário

Você é um novo desenvolvedor na Tailspin Toys, uma empresa fictícia que oferece financiamento coletivo para jogos de tabuleiro com temática de desenvolvimento. O backlog da equipe já está registrado como problemas do GitHub. Ele inclui recursos como filtragem e paginação, além de melhorias de qualidade, como acessibilidade e padrões de código.

## Escolha seu ambiente

O GitHub Copilot está disponível no ambiente em que você trabalha. Escolha aquele que melhor se adapta à sua forma de desenvolver. Cada workshop começa com sua própria configuração e usa o cenário compartilhado do Tailspin Toys.

### [GitHub Copilot CLI][cli]

Use o assistente baseado em agentes no terminal. Trabalhe com os modos Plan e Autopilot, instruções, skills, agentes personalizados, MCP do Playwright, Agent Merge e comandos de barra úteis.

### [Aplicativo GitHub Copilot][app]

Execute sessões de agentes em paralelo, alterne os modos de sessão, colabore em canvases e gerencie problemas e pull requests do GitHub no aplicativo para desktop.

### [Agente de nuvem do GitHub Copilot][cloud]

Atribua problemas do GitHub a um agente assíncrono, oriente o trabalho, acompanhe o progresso e revise os pull requests criados.

### [Visual Studio Code][vscode]

Use o GitHub Copilot no Visual Studio Code e no GitHub Codespaces. Trabalhe com o modo de agente do Copilot Chat, servidores MCP e agentes personalizados sem sair do editor.
